Rozšíření: Fronta příkazů

Doplněk GRAFIT: původní fragment není správné použití std::queue. Předávejte frontu referencí, používejte push()/pop() a nezávislé if pro souběžné vstupy; else-if propustí jen první příkaz. Původní fragment níže zůstává výkladovým podkladem, nikoli spustitelným příkladem.

Původní výkladový fragment C++

void InputHandler::handleInput(std::queue<Command*> q) {
    if (isPressed(BUTTON_X)) q.push_back(buttonX_);
    else if (isPressed(BUTTON_Y)) q.push_back(buttonY_);
    else if (isPressed(BUTTON_A)) q.push_back(buttonA_);
    else if (isPressed(BUTTON_B)) q.push_back(buttonB_);
}
void Game::loop() {
    while (true) {
        inputHandler.handleInput(commandQueue);
        while (!commandQueue.empty()) {
            commandQueue.front()->execute();
            commandQueue.pop_front();
        }
        // ...
    }
}

Observer

Pattern

Doplněk GRAFIT: v úplném C++ rozhraní musí být notifyObserver přístupné volajícímu (public); fragment vynechává části deklarace a správu životnosti.

Původní výkladový fragment C++

class Observer {
    virtual void notifyObserver(EventData event) = 0;
};

Původní výkladový fragment C++

class Subject {
    std::vector<Observer*> observers;
public:
    void addObserver(Observer* observer); // obvious
    void removeObserver(Observer* observer); // obvious
protected:
    void notifyObservers(EventData event) {
        for (auto observer: observers) {
            observer->notifyObserver(event);
        }
    }
};

Observer

Další rozšíření

Zpracování observerů je synchronnní; pozor na rychlost!

lze odložit provádění observerů odkládáním jejich notifikací do fronty,

případně lze využít multithreading (pozor na data races).

Předávání více informací:

do notifikace lze přidat bližší informace o změně stavu,

lze přidat i odkaz na subjekt, jeden observer potom může pozorovat více subjektů.

Subjekt nemusí nutně být nejmenší část herní scény:

typicky např. fyzikální engine může vyhodnocovat kolize objektů a posílat notifikace o zjištěných kolizích objektů.

Pro každý druh notifikací lze mít vlastní hierarchii subjektů a observerů

např. pomocí šablon Observer<EventData> a Subject<EventData>,

pozor na spotřebu paměti na registraci observerů!

Sequence

Pattern

Doplněk GRAFIT: std::queue používá pop(), nikoli pop_front(). Před front() ověřte neprázdnost, vlastnictví kroků a jejich životnost. Tento původní fragment není úplný spustitelný projekt.

Původní výkladový fragment C++

class Step {
public:
    virtual bool update() = 0;
};
class FoundationsStep : public Step;
class BuildingStep : public Step;
class BuiltStep : public Step;
class Sequence {
    std::queue<Step*> steps;
public:
    void update() {
        if (!steps.empty())
            if (steps.front()->update())
                steps.pop_front();
    }
};

Fronta příkazů a stavový automat · GRAFIT
Zařaďte příkazy a proveďte je postupně. Neplatný přechod ponechá stav beze změny.
    Didaktický doplněk GRAFIT: deterministická fronta FIFO a tři stavy. Skok i přikrčení jsou povoleny jen ze stání, dopad ze skoku a uvolnění dolů z přikrčení. Model neimplementuje fyziku, síť, herní smyčku ani správu paměti C++. Fronta má ochranný limit 30 příkazů.
