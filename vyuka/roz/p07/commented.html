Doplněk GRAFIT

Nejdříve určete pozitivní třídu

Vysvětlení GRAFIT

TP a FN se vztahují ke skutečně pozitivním případům; FP a TN ke skutečně negativním. Bez určení pozitivní třídy a orientace matice záměn je snadné zaměnit citlivost, přesnost a specificitu.

Doplněk GRAFIT

Čtyři čísla, několik otázek

Vysvětlení GRAFIT

Precision = TP/(TP+FP), recall = TP/(TP+FN), specificity = TN/(TN+FP). Accuracy počítá podíl všech správných rozhodnutí. Při nulovém jmenovateli je poměr nedefinovaný; dohodnuté náhradní konvence je nutné uvést.

Doplněk GRAFIT

Práh mění kompromis

Vysvětlení GRAFIT

ROC zobrazuje TPR proti FPR, křivka precision–recall zachycuje jiný pohled. Jediné číslo AUC nenahrazuje volbu provozního bodu ani cenu chyb. Precision se mění i s apriorní četností pozitivní třídy.

Doplněk GRAFIT

Nejistota odhadu

Vysvětlení GRAFIT

Výkon z konečného vzorku je odhad. Způsob dělení, závislosti mezi vzorky a interval nejistoty jsou součástí jeho interpretace. Téměř stejné skóre nemusí znamenat prokázaný rozdíl metod.

Doplněk GRAFIT

Accuracy umí skrýt neúspěch

Řešený syntetický příklad · GRAFIT

Při 990 negativních a 10 pozitivních případech má klasifikátor „vždy negativní“ accuracy 99 %, ale recall pozitivní třídy 0 %. Precision je nedefinovaná, protože nebyl předpovězen žádný pozitivní případ.

Na co dát pozor

Nezaměňujte precision za recall ani jeden údaj bez rozmyslu nepřekládejte jako „přesnost“. Uvádějte vzorec, pozitivní třídu a jmenovatel.

Testing set choice - different testing sets may rank differently
classifiers. Thus conclusions drawn from a single test
set can be unreliable.
Training set choice - some classifiers (e.g. decision trees,neural

set can cause substantial changes of the classifier
trained on this set.
Learning randomness - some learning methods have a random
component (e.g. initialization in the backpropagation
algorithm,genetic algorithms). Thus the same Ti
