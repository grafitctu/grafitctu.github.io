Volba programovacího jazyka je nezávislá na češtině a angličtině.Switch examples between Python and C++; C++ is the default. Pseudocode remains a separate option. The programming language is independent of the Czech/English interface.

Stáhnout C++ projekt a dataDownload the C++ project and data (ZIP) · Kompilace na Windows a LinuxuBuild on Windows and Linux · Python ukázkyPython examples

C++ projekt používá C++17 a CMake, obsahuje Makefile a zdrojový kód LIBSVM včetně licence. Další knihovny neinstalujete.The C++17 project provides CMake, a Makefile and the LIBSVM sources with their licence. No additional libraries need to be installed.

cd examples/cpp
cmake -S . -B build
cmake --build build --config Release

Linux/macOS: ./build/check_pca. Windows s generátorem Visual Studio: .\build\Release\check_pca.exe. Další příkazy a formát CSV jsou v README projektu.Linux/macOS: ./build/check_pca. With the Visual Studio generator on Windows: .\build\Release\check_pca.exe. See the project README for more commands and the CSV format.
