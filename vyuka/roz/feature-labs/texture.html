Normalizace a příznakyNormalization and features

q = ⌊G · I/256⌋,   Pᵢⱼ = Cᵢⱼ / Σ C
kontrastcontrast = Σ (i − j)² Pᵢⱼ
homogenitahomogeneity = Σ Pᵢⱼ / (1 + (i − j)²)
ASM = Σ Pᵢⱼ²

I je jas 0–255. Normalizovaná matice P má součet 1. Při započtení opačných dvojic C nahradíme C + Cᵀ. Přičteme i obrácenou verzi dvojice se stejnými úrovněmi, takže počet záznamů se zdvojnásobí.I is brightness from 0 to 255. The normalized matrix P sums to 1. Counting reverse pairs replaces C by C + Cᵀ. Same-level pairs also contribute twice, so the number of entries counted doubles.

Kontrast je vysoký, když leží hodně hmoty daleko od diagonály. Homogenita váží nejvíc diagonálu. ASM roste, když se hmota soustředí do mála buněk.Contrast is high when much of the mass is far from the diagonal. Homogeneity gives the diagonal the greatest weight. ASM increases when the mass concentrates in fewer cells.

Od součtů k invariantůmFrom sums to invariants

mpq = Σ xᵖ yᑫ,   x̄ = m₁₀/m₀₀,   ȳ = m₀₁/m₀₀
μpq = Σ (x − x̄)ᵖ (y − ȳ)ᑫ
ηpq = μpq / m₀₀1+(p+q)/2
φ₁ = η₂₀ + η₀₂,   φ₂ = (η₂₀ − η₀₂)² + 4η₁₁²

Centrování odstraní posun. První dva Huovy invarianty skládají normované momenty druhého řádu tak, aby přežily otočení. U součtů přes středy pixelů se při zvětšení mění vzorkování. Při integraci přes celé jednotkové čtverce přičteme k μ₂₀ a μ₀₂ vždy m₀₀/12. Pro stejnou spojitou plochu pak invarianty přežijí i toto zvětšení.Centering removes translation. The first two Hu invariants combine normalized second-order moments to preserve their values under rotation. With pixel-centre sums, enlargement changes the sampling. Integrating over unit squares adds m₀₀/12 to μ₂₀ and to μ₀₂. For the same continuous shape, the invariants then also survive this scale change.
