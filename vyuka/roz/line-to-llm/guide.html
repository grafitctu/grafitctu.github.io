Základní pojmyBasic terms

vzorek / sampleJeden řádek pozorování.One observed data row.
příznak / featureČíselný popis vstupu, zde například výkon auta.A numerical input measurement, such as car horsepower.
cíl / targetHodnota, kterou se učíme předpovídat.The value we learn to predict.
parametr / parameterVáha nebo posun měněný při učení.A weight or bias updated during training.
aktivace / activationVýstup neuronu po použití nelineární funkce.A neuron output after applying a nonlinear function.
embeddingVektor vyhledaný v tabulce pomocí ID tokenu.A vector looked up in a table using a token ID.
attentionVážené skládání hodnot podle skóre dotaz–klíč.A weighted mixture of values using query–key scores.
logitReálné skóre před převodem na pravděpodobnost.A real-valued score before conversion to probability.
softmaxNormalizace skóre do nezáporných čísel se součtem 1.A normalization into nonnegative numbers that sum to 1.

Otázky pro vyučujícíhoQuestions for the instructor

  • Před změnou parametru nechte studenty předpovědět směr změny.Ask students to predict the direction of a change before moving a parameter.
  • U přímky důsledně oddělte MSE a MAE. Model učíme podle MSE, ale obě chyby můžeme měřit.Keep MSE and MAE distinct. We train using MSE, while measuring both errors.
  • U součtu ReLU upozorněte na pevné polohy zlomů. V obecné síti se mohou učit také jejich polohy.Point out the fixed bend locations in the ReLU sum. A general network may learn bend locations too.
  • U attention nechte jednu dvojici spočítat skalární součin a druhou výslednou směs hodnot.Have one pair calculate the dot product and another calculate the value mixture.
  • U generování se váhy nemění. Změna teploty je nastavení výběru z výstupního rozdělení.Generation keeps weights fixed. Temperature changes selection from the output distribution.
