# NI-ROZ / ANI-ROZ: Regression, neurons and language models

Česky: rozbalte celý offline ZIP a otevřete index.html. Přepínač v záhlaví volí češtinu nebo angličtinu. Guide / ZIP obsahuje plán a soubory.
English: extract the entire offline ZIP and open index.html. Choose Czech or English in the header. Guide / ZIP contains the plan and files.

19 slides, approximately 90 minutes. All plots recalculate locally. External links need internet access.

C++17: CMake and Makefile are provided. Windows: Visual Studio with its C++ workload.
Python: install NumPy using requirements.txt.

The text example uses hand-authored teaching weights, one attention head, 3-dimensional vectors, up to 8 input tokens and 5 output candidates. GPT-2's architecture is described separately with primary sources.
