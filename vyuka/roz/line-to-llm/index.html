Funkce a regularizaceFunction and regularization

ŷ = β₀ + β₁z + Σ cⱼ max(0, z − tⱼ)

Minimalizujeme součet čtverců chyb + λΣβⱼ² pro j ≥ 1. Posun β₀ nepenalizujeme. Větší λ omezuje velikost koeficientů.We minimize the sum of squared errors + λΣβⱼ² for j ≥ 1. The intercept β₀ is not penalized. Larger λ limits coefficient magnitudes.

Váhy a jsou nezáporné a jejich součet je 1. Každý token přispěje svým vektorem v, násobeným vahou a.Weights a are nonnegative and sum to 1. Each token contributes its value vector v multiplied by weight a.

Posuvník τ je doplňkový pokus s ostrostí vah. Při τ = 1 jde o standardní škálované dot-product attention. Váhy popisují tuto směs hodnot v jedné hlavě.The τ slider is an extra experiment with weight sharpness. At τ = 1 this is standard scaled dot-product attention. These weights describe the value mixture in one head.

Výstupní skóre a pravděpodobnostiOutput scores and probabilities

Pro každý výstupní token spočítáme afinní skóre, logit. Softmax porovná všechna skóre v našem malém výstupním slovníku a převede je na pravděpodobnosti.For every output token, compute an affine score, called a logit. Softmax compares all scores in our small output vocabulary and turns them into probabilities.

ℓᵢ = wᵢᵀz + bᵢ
pᵢ = exp(ℓᵢ/T) / Σⱼ exp(ℓⱼ/T)

Tento výstup patří k vybranému dotazu. Ukázka má pět výstupních symbolů a ručně zvolené váhy. Zobrazená procenta vznikají z uvedených čísel.This output belongs to the selected query. The example has five output symbols and hand-chosen weights. The displayed percentages come from the numbers shown.

Pro stabilní výpočet odečítáme od všech logitů jejich maximum. Pravděpodobnosti se tím nezmění.For numerical stability, subtract the maximum logit from every logit. This leaves probabilities unchanged.

Jeden další tokenOne more token

Generování používá poslední pozici prefixu. Nový token připojíme a provedeme další dopředný průchod. Parametry přitom zůstávají stejné.Generation uses the last prefix position. Append a new token and run another forward pass. Parameters stay fixed.
