Accuracy je podíl správných rozhodnutí. Macro-F1 průměruje F1 jednotlivých tříd stejnou vahou. Balanced accuracy průměruje recall tříd. Tato čísla odpovídají různým otázkám.Accuracy is the fraction of correct decisions. Macro-F1 averages class F1 scores with equal weight. Balanced accuracy averages class recall. These numbers answer different questions.

  • Které metody mají velký rozdíl mezi tréninkem a validací?Which methods have a large training–validation gap?
  • Liší se pořadí podle accuracy a macro-F1?Does ranking by accuracy differ from ranking by macro-F1?
  • Které dvojice číslic zvolený model zaměňuje?Which digit pairs does the chosen model confuse?

V JSON najdete validation_confusion_matrix a validation_error_examples pro validační volbu. Časy měření závisí na počítači. Bez opakování a intervalů nepovažujte malé rozdíly za jisté pořadí metod.The JSON includes validation_confusion_matrix and validation_error_examples for the validation choice. Timings depend on the machine. Without repeated runs and uncertainty estimates, small differences do not establish a reliable ranking.

5. Strom, random forest a boosting5. A tree, a random forest and boosting

50–60 minut. V capacity_study porovnejte hloubky 1, 3, 8 a neomezenou hloubku. Potom porovnejte strom s forest a boosting v hlavní tabulce.50–60 minutes. In capacity_study, compare depths 1, 3, 8 and unlimited depth. Then compare the tree with forest and boosting in the main table.

Random forest kombinuje stromy s randomizací vzorků a příznaků. Gradient boosting přidává malé stromy postupně podle záporného gradientu ztráty. Parametr learning_rate omezuje příspěvek dalšího kroku.A random forest combines trees using randomized samples and features. Gradient boosting adds small trees sequentially using the negative loss gradient. learning_rate limits the contribution of each new step.

Fm(x) = Fm−1(x) + η hm(x)

F je souborové skóre, h nový slabý model a η rychlost učení. Pro kvadratickou regresní ztrátu odpovídá směr obyčejným reziduím. U klasifikační log-loss se učíme jiné pseudoreziduum, nikoli rozdíl kódů tříd.F is the ensemble score, h the new weak model and η the learning rate. With squared regression loss, the direction corresponds to ordinary residuals. Classification log-loss gives a different pseudo-residual, not a difference between class IDs.

6. K-means bez názvů číslic6. K-means without digit names

60–70 minut. K-means se učí na trénovacích obrázcích bez y. K = 10 ovšem dodáváme jako známý počet shluků. Na validaci následně pro vyhodnocení využijeme její skutečné třídy.60–70 minutes. K-means learns from training images without y. We supply K = 10 as a known cluster count. We later use validation labels to evaluate the resulting partition.

cluster_ids = kmeans.predict(X_validation_scaled)
ari = adjusted_rand_score(y_validation, cluster_ids)

V clustering najdete ARI i výsledek po přejmenování shluků. Najdete také záměrně nevhodnou raw accuracy porovnávající ID shluku přímo s kódem číslice.clustering includes ARI and its value after renaming clusters. It also includes an intentionally unsuitable raw accuracy that directly compares cluster IDs with digit codes.

Pro pozdější klasifikaci by mapování shluků na třídy muselo vzniknout na trénovacích nebo validačních datech. Mapování odvozené až z testových štítků mění význam experimentu.For a later classification system, the cluster-to-class mapping would have to come from training or validation data. A mapping derived from test labels changes the meaning of the experiment.

7. Regrese a nové příznaky7. Regression and new features

70–80 minut. Sekce regression používá samostatná syntetická data: y = 0,8x² − 0,7x + šum. Porovnejte lineární regresi s příznakem x a se dvěma příznaky x, x². Oba modely zůstávají lineární v koeficientech.70–80 minutes. regression uses separate synthetic data: y = 0.8x² − 0.7x + noise. Compare linear regression using x with the same estimator using x and x². Both models stay linear in their coefficients.

MAE průměruje absolutní chybu. RMSE je odmocnina průměrné kvadratické chyby, proto silněji reaguje na velké odchylky. Menší hodnota je zde lepší.MAE averages absolute errors. RMSE is the square root of mean squared error and therefore reacts more strongly to large errors. Smaller values are better here.
