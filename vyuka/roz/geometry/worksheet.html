Pracovní list: geometrie datWorksheet: the geometry of data

90 minut, práce ve dvojicích. Nejdříve odhad, potom klikátko a nakonec výpočet.90 minutes in pairs. Predict first, use the interactive examples next, calculate afterwards.

Otevřete index.html. Webová část nepotřebuje instalaci. Všechny interaktivní ukázky fungují bez internetu. Videa najdete pouze ve zdrojových odkazech. Příkaz níže případně otevře balík přes místní HTTP server, což pomůže přísnějším prohlížečům.Open index.html. The web part needs no installation. All interactive examples work offline. Videos appear only in source links. The command below can serve the package over local HTTP if your browser applies stricter file restrictions.

python -m http.server 8789 --bind 127.0.0.1
# Open http://127.0.0.1:8789/ in your browser.

1. DBSCAN a příznaky1. DBSCAN and features

0–15 min

U DBSCAN nejprve měňte jen ε, potom jen min_samples. Kliknutím na bod si ověřte počet sousedů. Na slidu 4 pak zkuste ručně oddělit třídy přímkou. Přepněte na nový příznak a měňte výšku roviny i střed kružnice. Otočte 3D pohled. Všimněte si, co mění rozdělení bodů a co jen jejich zobrazení.For DBSCAN, first change only ε, then only min_samples. Click a point to inspect its neighbour count. On slide 4, try separating the classes with a line. Switch to the new feature and change the plane height and circle centre. Rotate the 3D view. Distinguish changes to classification from changes to the view.

2. Ruční hledání osy2. Finding an axis manually

15–35 min

Po krokované ukázce projekce otevřete klikátko na základním eliptickém mraku. Maximum zatím neukazujte. Vyzkoušejte alespoň čtyři úhly a zapište úhel, varianci a zachovaný podíl. Potom teprve ukažte maximum.After the step-by-step projection example, open the basic elliptical cloud. Do not reveal the maximum yet. Try at least four angles, recording angle, variance and retained fraction. Only then reveal the maximum.

Otočení osy o 180° má zachovat varianci. Před ověřením napište proč.Rotating the axis by 180° should preserve variance. Explain why before checking.

3. Ztracená informace3. Information loss

35–45 min

Po ručním hledání zapněte „Vlastní vektory a čísla“. Porovnejte u₁ s nalezenou osou: Variance v tomto směru má odpovídat λ₁. Přepněte na kolmý směr u₂ a porovnejte s λ₂. Potom osu ručně otočte. Co se změní a co zůstane stejné?After searching manually, enable “Eigenvectors and eigenvalues”. Compare u₁ with your axis: Variance along this direction should equal λ₁. Switch to the perpendicular direction u₂ and compare with λ₂. Then rotate the orange axis manually. What changes and what stays the same?

U každého bodu zachováme jedinou souřadnici. Rozmyslete si, jak z ní bod přibližně zrekonstruovat.We keep one coordinate per point. Think about reconstructing an approximate point from it.

4. Protipříklady a jednotky4. Counterexamples and units

45–60 min

Vyzkoušejte kruhový mrak, odlehlý bod a dvě třídy. Potom obnovte základní mrak, vynásobte druhý příznak osmi a porovnejte standardizaci.Try the circular cloud, outlier and two-class examples. Then restore the basic cloud, multiply feature two by eight and compare standardization.

5. Výpočet stejného čísla5. Calculating the same value

60–70 min

Teprve teď projděte rovnice. Spočítejte projekce pro dva směry a jejich výběrový rozptyl. Porovnejte s uᵀCu. Uveďte, proč má být u jednotkový vektor.Now read the equations. Calculate projections and sample variance for two directions. Compare with uᵀCu. Explain why u must have unit length.

6. Obrázky a rekonstrukce6. Images and reconstruction

70–85 min

Nejprve otevřete „Co je složka?“. Porovnejte průměrný obrázek a tři vzory vah. Přepněte vybranou číslici a sledujte, co zůstává stejné a co se změní. Zkuste k = 0, 1, 2 a 3. Potom v rekonstrukcích všech číslic porovnejte 4, 8, 16, 32 a 64 složek.First open “What is a component?”. Compare the mean image and three weight patterns. Select another digit and observe what stays the same and what changes. Try k = 0, 1, 2 and 3. Then compare reconstructions of all digits at 4, 8, 16, 32 and 64 components.

Vysvětlete rozdíl mezi vzorem uⱼ, koeficientem zⱼ jednoho obrázku a vlastním číslem λⱼ trénovacího souboru. Oddělte zachovaný trénovací rozptyl, MSE odložených obrázků a jejich čitelnost pro člověka.Explain the difference between pattern uⱼ, score zⱼ for one image, and eigenvalue λⱼ of the training set. Distinguish retained training variance, held-out image MSE and human readability.

7. Odevzdání7. Submission

85–90 min

Odevzdejte záznam čtyř úhlů, jeden DBSCAN pokus, srovnání počtu složek u číslic a tři věty o omezeních. Samotné nalezení maxima nestačí.Submit four angle measurements, one DBSCAN experiment, a digit component-count comparison, and three sentences about limitations. Finding the maximum alone is insufficient.

Text je vybraný. Zkopírujte jej do editoru a uložte jako TXT.The text is selected. Copy it into an editor and save it as TXT.

Odpovědi se ukládají jen v tomto prohlížeči a nikam se neposílají. Exportujte je před zavřením.Answers stay in this browser and are not sent anywhere. Export them before closing.

Volitelný PythonOptional Python

Ve složce balíku vytvořte prostředí a nainstalujte requirements.txt. Python 3.11 nebo novější. Pro notebook či editor použijte stejné prostředí.Create an environment in the package folder and install requirements.txt. Use Python 3.11 or later, and select the same environment in your editor.

# Windows PowerShell:
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe examples/pca_dbscan.py

# Linux / macOS:
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python examples/pca_dbscan.py

Python používá stejná uložená syntetická data jako matematické ověření klikátka. Pro klasifikační pokus fitujte preprocessing pouze na tréninku.Python uses the same saved synthetic points used to verify the interactive calculations. For a classification experiment, fit preprocessing on training data only.

Která čísla zůstala stejná a proč?Open the new component-count slide. Try k = 0, 1, 8 and 64, then the 90%, 95% and 99% buttons. Record the smallest k for each threshold and the MSE of the same image. Then select another image. Which values stayed the same, and why?
