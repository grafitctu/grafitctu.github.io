Abstract

This report tests Local Binary Patterns (LBP) for iris classification. It compares different distance functions and LBP settings in terms of classification accuracy. Combining the best-performing choices achieved an average accuracy of 92.86% with a random 7:3 train/test split. In addition to the classifier, the work provides a framework for testing other classifiers, distance functions, and features.

1. Introduction

Reliable identification is a basic requirement of modern security systems. It can be provided by identification cards, chips, or biometric data. Biometrics are especially attractive because they can provide an identification mechanism that is difficult to forge or transfer to another person.

Biometric security features are now common at airports. Biometric passports rely mainly on face identification, but the stored information can also be extended with fingerprints or iris images. In both cases, comparison is usually performed under controlled laboratory conditions. Classifying iris images captured with an ordinary mobile device in unconstrained conditions is considerably harder. This report presents a method for classifying such iris images.

Local Binary Patterns (LBP) are an intuitive feature introduced in the selected paper. The basic idea is to construct a grayscale-invariant and rotation-invariant texture descriptor that describes the relation between a pixel and its neighbourhood. This work tests whether the descriptor can also be used for iris classification.

2. Classification

The input consists of 813 RGB iris images, 600 x 100 pixels, in PNG format. The images are already normalized, but their quality varies. The most common problems are:

  • a blurred sample;
  • reflections of light;
  • a reflection of a building or another object in front of the subject;
  • incorrect iris detection by the normalization algorithm.

To reduce some of these effects, all images are blurred with a Gaussian filter with width k = 7 and sigma = 5. If the image is converted to another colour space, the conversion is performed before blurring.

2.1. Classifier

The experiments use a k-nearest-neighbours (kNN) classifier. A kNN classifier is defined by a training set T of pairs (Xi, omegai), a distance function d, and a tested feature vector X. It returns a class label omega. The set NX contains the k nearest training samples, that is, for every n in NX and every t outside N_X, d(n,X) <= d(t,X). The output is the majority class among the k neighbours.

The experiments use k = 3 and, in the final comparison, also k = 1.

2.2. Features

An LBP code is a binary string describing the relation between a central pixel and its neighbouring pixels. For a central pixel c with value hc and P neighbours with values hp, the code is formed from the signs of hp - hc. The usual LBP_{P,R} variant uses P evenly distributed neighbours at distance R from the central pixel.

The basic code is not rotation invariant. Rotation invariance can be obtained by selecting the rotation-equivalent code with the smallest value. For P = 8 this reduces the number of possible codes from 256 to 36. The experiments do not use rotation invariance because the input images are assumed to be already normalized.

3. Experiments

The experiments compare feature choices and distance functions. The data are split into training and test sets in the following ratios:

  • 1 : N - 1 (73 training images and 740 test images);
  • 1 : 1 (420 training images and 393 test images);
  • 7 : 3 (599 training images and 214 test images).

Unless stated otherwise, the experiments use kNN with k = 3 and 250 random splits.

3.1. Comparison of colour spaces

The first question is how much accuracy can be obtained with simple pixel-based features. The experiments compare RGB and Lab. Lab was selected because it represents the visible spectrum in a way that is more closely related to perceived colour. The L2 (Euclidean) distance is used for comparison.

The difference between RGB and Lab is small. With the L2 metric, Lab is on average 0.75 percentage points more accurate, and the difference grows to 1.3 percentage points when only 16% of the original sample is compared. The following average accuracies are used as reference values for later experiments: 30.5% for the 1 : N - 1 split, 67.5% for 1 : 1, and 75.9% for 7 : 3.

3.2. LBP_{8,R} with different distances

The next experiment identifies a useful distance R for extracting LBP features. Computing LBP for every pixel is expensive, so only 50 random 1 : N - 1 splits are used. The distance between two images is the sum of the L2 distances between their LBP pixels, using only the central 36% of the sample.

For small distances R = 1, R = 2, and R = 4, the luminance component L has a visible effect. The best values are obtained around R = 16: the average accuracy is 41.1% for L, 41.9% for the a component, and 41.5% for the b component.

3.3. Global histogram and the distance function

Pixel-wise comparison is computationally expensive and is not sufficiently robust to shifts. The report therefore also implements a histogram variant. Individual LBP_{8,8} codes are assigned to bins 0 through 255, and the resulting histograms are compared with L2 and the symmetric chi-squared distance.

The distance function has a strong effect on classification. On the tested histograms, chi-squared accuracy is up to ten percentage points higher than L2 accuracy. This experiment uses only the L component of the Lab colour space.

3.4. Pixel-wise, global, and local histograms

The report compares three approaches: pixel-wise LBP, one global histogram, and local histograms. For the local variant, the image is divided into a 60 x 10 grid of 10 x 10 pixel blocks. A histogram is computed for every block, preserving some local information while retaining the robustness of histograms to small shifts.

The global histogram is not suitable for the 1 : N - 1 split. The local-histogram method performs best, with average accuracies of 43.5% for 1 : N - 1, 79.1% for 1 : 1, and 85.5% for 7 : 3.

4. Results

The final classifier uses 60 x 10 local LBP histograms, each computed over a 10 x 10 pixel block. The L component uses LBP{8,8}; the a and b components use LBP{8,16}. Histograms are compared with the symmetric chi-squared distance, and the total distance is the sum of the local distances.

The final comparison uses kNN with k = 1 and k = 3. The split is either completely random or constrained to contain at least one fixed (stable) sample. Distances are cached to make 250 repeated splits practical.

5. Summary

The project produced a C++ framework for testing iris classification with OpenCV. The framework was evaluated in several experiments and produced a classifier with an average accuracy of 92.86% on the 7 : 3 split, compared with 75.9% for the naive reference method.

Computing LBP for every pixel is expensive. A genetic algorithm reduced the number of compared blocks by approximately one half with a small improvement in accuracy. More systematic experiments with genetic algorithms could reduce the computational cost further and might improve accuracy by discarding blocks that do not contribute to successful classification.
