Od jedné šipky k PCAFrom one arrow to PCA

Kam matice pošle šipku?Where does the matrix send the arrow?

Posuňte mřížku a porovnejte, kam míří původní šipka v a její obraz Av. První řádek matice určuje novou souřadnici x, druhý určuje y.Move the grid and compare the original arrow v with its image Av. The first matrix row gives the new x coordinate. The second gives y.

Které šipky zůstanou na své přímce?Which arrows stay on their own line?

Otáčejte jednotkovou šipkou u. Většinu směrů matice změní. Najděte dvě přímky, na kterých u a Au leží i po transformaci. Pro takový vektor platí Au = λu.Rotate the unit arrow u. The matrix turns most vectors. Find two lines on which u and Au stay together after the transformation. For such a vector, Au = λu.

Kolikrát se šipka prodlouží?By what factor does an arrow stretch?

Zvolte jednu ze dvou nalezených přímek. Jednotková šipka na první se prodlouží na 2, na druhé se zkrátí na 0,5. To jsou vlastní čísla této matice. Podíl délek obecně dává |λ|. V tomto příkladu jsou obě λ kladná.Pick one of the two lines you found. A unit arrow on the first grows to length 2. On the second it shrinks to 0.5. These are the eigenvalues of this matrix. In general the length ratio gives |λ|. Both eigenvalues here are positive.

Odkud se vzala právě tato matice?Where did this particular matrix come from?

Proč je první vlastní směr právě PC1?Why is the first eigendirection PC1?

Nyní víme, že Σ = A. Její vlastní vektory určují dvě kolmé osy dat. Otočte zkušební osou a sledujte rozptyl průmětů. Největší je 2 ve směru PC1, na kolmé ose PC2 je 0,5. První osa tak zachycuje 2 / (2 + 0,5) = 80 % celkového rozptylu.We now know that Σ = A. Its eigenvectors give two perpendicular axes of the data. Turn the trial axis and watch the variance of the projections. It reaches 2 along PC1 and 0.5 on the perpendicular PC2. The first axis captures 2 / (2 + 0.5) = 80% of the total variance.

Jak ze dvou čísel vznikne jedno skóre?How do two numbers become one score?

Vyberte měření a posouvejte body k ose PC1. Kolmý průmět vybraného bodu má na této ose souřadnici z = u₁ᵀx, kde x je centrovaný bod. Pro první měření je x = (1,5; 0,5), takže z = (1,5 + 0,5) / √2 = √2. V původních osách leží jeho průmět v bodě (1; 1).Choose a measurement and move the points towards PC1. The perpendicular projection of the selected point has coordinate z = u₁ᵀx along this axis, where x is the centred point. For the first measurement x = (1.5, 0.5), so z = (1.5 + 0.5) / √2 = √2. Its projection in the original axes is (1, 1).

Co říká rozložení skóre?What does the distribution of scores tell us?

Položte PC1 vodorovně. Každé měření má na ní jedno skóre. Seskupte blízká skóre do intervalů a v každém naskládejte body nad sebe. Výška sloupce nyní udává počet měření. Kladné skóre znamená kladný součet obou odchylek ve zvolených jednotkách.Lay PC1 horizontally. Each measurement now has one score. Group nearby scores into bins and stack the dots in each bin. The column height now counts measurements. A positive score means that the two deviations, in the chosen units, add up to a positive value.

Point transform(const Matrix& matrix, Point v) {
    Point result{};
    for (int row = 0; row < 2; ++row)
        result[row] = matrix[row][0] * v[0] + matrix[row][1] * v[1];
    return result;
}
def transform(matrix, vector):
    x, y = vector
    return tuple(row[0] * x + row[1] * y for row in matrix)
double direction_error(const Matrix& matrix, Point u) {
    Point au = transform(matrix, u);
    // The determinant of the two arrows is zero when they lie on one line.
    return std::abs(u[0] * au[1] - u[1] * au[0]);
}
def direction_error(matrix, u):
    ax, ay = transform(matrix, u)
    # The determinant of the two arrows is zero when they lie on one line.
    return abs(u[0] * ay - u[1] * ax)
double stretch(const Matrix& matrix, Point u) {
    Point au = transform(matrix, u);
    return std::hypot(au[0], au[1]) / std::hypot(u[0], u[1]);
}
def stretch(matrix, u):
    ax, ay = transform(matrix, u)
    return math.hypot(ax, ay) / math.hypot(*u)
Data covariance(const vector<Point>& measurements) {
    double n = static_cast<double>(measurements.size());
    Point mean{};
    for (auto [h, w] : measurements) { mean[0] += h; mean[1] += w; }
    mean[0] /= n;
    mean[1] /= n;
    Data data{};
    for (auto [height, weight] : measurements) {
        Point x{(height - mean[0]) / 5, (weight - mean[1]) / 4};
        data.points.push_back(x);
        for (int i = 0; i < 2; ++i)
            for (int j = 0; j < 2; ++j)
                data.covariance[i][j] += x[i] * x[j];
    }
    for (auto& row : data.covariance)
        for (double& entry : row) entry /= n - 1;
    return data;
}
def covariance(measurements):
    n = len(measurements)
    mean_h = sum(h for h, w in measurements) / n
    mean_w = sum(w for h, w in measurements) / n
    points = [((h - mean_h) / 5, (w - mean_w) / 4) for h, w in measurements]
    hh = sum(h * h for h, w in points) / (n - 1)
    hw = sum(h * w for h, w in points) / (n - 1)
    ww = sum(w * w for h, w in points) / (n - 1)
    return points, ((hh, hw), (hw, ww))
Axes principal_axes(const Matrix& matrix) {
    double a = matrix[0][0], b = matrix[0][1], d = matrix[1][1];
    double gap = std::hypot(a - d, 2 * b);
    double angle = std::atan2(2 * b, a - d) / 2;
    Point pc1{std::cos(angle), std::sin(angle)};
    return {{(a + d + gap) / 2, (a + d - gap) / 2},
            pc1, {-pc1[1], pc1[0]}};
}
def principal_axes(matrix):
    (a, b), (_, d) = matrix
    gap = math.hypot(a - d, 2 * b)
    eigenvalues = ((a + d + gap) / 2, (a + d - gap) / 2)
    angle = math.atan2(2 * b, a - d) / 2
    pc1 = (math.cos(angle), math.sin(angle))
    pc2 = (-pc1[1], pc1[0])
    return eigenvalues, pc1, pc2
vector<double> project(const vector<Point>& points, Point axis) {
    vector<double> scores;
    for (auto [h, w] : points)
        scores.push_back(h * axis[0] + w * axis[1]);
    return scores;
}
def project(points, axis):
    return [h * axis[0] + w * axis[1] for h, w in points]
vector<int> histogram(const vector<double>& scores, int bins) {
    auto [low, high] = std::minmax_element(scores.begin(), scores.end());
    vector<int> counts(bins, 0);
    for (double score : scores) {
        double relative = *high > *low ? (score - *low) / (*high - *low) : 0;
        int index = std::min(static_cast<int>(relative * bins), bins - 1);
        ++counts[index];
    }
    return counts;
}
def histogram(scores, bins):
    low, high = min(scores), max(scores)
    counts = [0] * bins
    for score in scores:
        relative = (score - low) / (high - low) if high > low else 0
        index = min(int(relative * bins), bins - 1)
        counts[index] += 1
    return counts

PC1 ručně na čtyřech bodechFind PC1 by hand for four points

Vezměte body (−2, −1), (−1, −2), (1, 2) a (2, 1). Průměr obou souřadnic je nula. Součet čtverců v každém sloupci je 10. Součet součinů přes řádky je 2 + 2 + 2 + 2 = 8. Výběrovou kovarianci získáte dělením třemi.Take the points (−2, −1), (−1, −2), (1, 2) and (2, 1). Both coordinate means are zero. Each column has a sum of squares of 10. Across the rows the products add to 2 + 2 + 2 + 2 = 8. Divide by three for the sample covariance.

Matice má na diagonále 10/3 a mimo ni 8/3. Vynásobte jí vektor (1, 1). Vyjde (6, 6), takže směr se zachoval a vlastní číslo je 6. Pro (1, −1) vyjde (2/3, −2/3). Větší vlastní číslo určí PC1. Její jednotkový vektor je (1, 1)/√2 a první bod má na této ose souřadnici −3/√2. Kolik procent rozptylu tato osa zachytí?The diagonal of the matrix is 10/3 and the off-diagonal is 8/3. Multiply it by (1, 1). You get (6, 6), so the direction is preserved and its eigenvalue is 6. For (1, −1) you get (2/3, −2/3). The larger eigenvalue identifies PC1. Its unit vector is (1, 1)/√2, and the first point projects to −3/√2. What percentage of the variance lies on this axis?

6 / (6 + 2/3) = 0.9 = 90 %.
