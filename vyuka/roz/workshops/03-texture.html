Pruhy mají šířku dva pixely. Dva kroky doprava vždy vedou do pruhu opačného jasu. Dvojice 0 → 3 a 3 → 0 dají kontrast 9. Dva kroky dolů zůstanou ve stejném pruhu a kontrast je 0. Po čtyřech krocích doprava se vzor opakuje. Histogram je ve všech případech stejný. Ze změny kontrastu tak vyčtete směr i opakování textury.Each stripe is two pixels wide. Two steps right always reach the opposite grey level. Pairs 0 → 3 and 3 → 0 give a contrast of 9. Two steps down stay in one stripe and give a contrast of 0. Four steps right reach the same level again. The histogram stays the same throughout. The change in contrast reveals both direction and repetition.

P[i,j] je podíl dvojic s jasy i a j mezi všemi platnými dvojicemi. Kontrast = Σ(i−j)²P[i,j]. Dva stejné jasy přidají do svého políčka jeden výskyt a do kontrastu nulu. Čím více dvojic s velkým rozdílem jasů potkáme, tím větší je kontrast v tomto směru a vzdálenosti.P[i,j] is the fraction of valid pairs with grey levels i and j. Contrast = Σ(i−j)²P[i,j]. Two equal levels add one count to their cell and zero to the contrast. More pairs with large grey-level differences mean higher contrast at this direction and distance.

Co když spočítáme kovarianci přímo z jasů sousedů?What if we calculate covariance from the neighbouring grey levels themselves?

Každou platnou dvojici z pravého obrázku zapište jako řádek (jas A, jas B). Nyní se i kovariance mění se směrem. Celý výpočet jde udělat z GLCM. Četnost C[i,j] říká, kolikrát máme započítat řádek (i,j). Na okraji započítáme pouze dvojice, pro které existují oba pixely.Write each valid pair from the right-hand image as a row (grey level A, grey level B). This covariance also depends on direction. The GLCM contains everything needed for the calculation. C[i,j] tells us how many times to include the row (i,j). At an edge a pair counts only if both pixels exist.

Pro M dvojic vypočteme jejich dva průměry ā a b̄. Výběrová kovariance je Σᵢⱼ C[i,j] (i − ā)(j − b̄) / (M − 1). Normalizovaná GLCM P[i,j] = C[i,j]/M má součet 1. Kovariance shrne společné kolísání jedním číslem, v GLCM dál vidíme četnost každého konkrétního přechodu.For M pairs, compute the two means ā and b̄. The sample covariance is Σᵢⱼ C[i,j] (i − ā)(j − b̄) / (M − 1). The normalised GLCM P[i,j] = C[i,j]/M sums to 1. Covariance summarises joint variation in one number, while the GLCM gives the frequency of each particular transition.

Jak číst velikosti, znaménka a jednotkyReading sizes, signs and units

Pro d příznaků má S velikost d × d a je symetrická. Jednotkou buňky je součin jednotek obou příznaků. V ukázce počítáme R = ⌊R₈/64⌋ a G = ⌊G₈/64⌋, kde R₈ a G₈ jsou původní hodnoty 0 až 255. Součet součinů odchylek dělíme n − 1, kde n je počet pozorování.For d features, S has d rows and d columns and is symmetric. An entry has the product of the two feature units. Here R = ⌊R₈/64⌋ and G = ⌊G₈/64⌋, where R₈ and G₈ are the original values from 0 to 255. We divide the sum of products of deviations by n − 1.

Pro Q úrovní jasu má C velikost Q × Q. Zde je q = ⌊(R₈ + G₈ + B₈)/192⌋ a Q = 4, stejně jako v pokusu s výřezem výše. Buňky obsahují nezáporné počty. Na diagonále mají A i B stejný jas. Při počítání v jednom směru může C[i,j] vyjít jinak než C[j,i]. Obrácením směru se matice transponuje.For Q grey levels, C has Q rows and Q columns. Here q = ⌊(R₈ + G₈ + B₈)/192⌋ and Q = 4, as in the patch experiment above. Entries are nonnegative counts. On the diagonal, A and B have the same level. In a directed GLCM, C[i,j] can differ from C[j,i]. Reversing the offset transposes the matrix.

Covariance sample_covariance(const std::vector<Pair>& rows) {
    if (rows.size() < 2) throw std::invalid_argument("Sample covariance needs two or more observations");
    const double n = static_cast<double>(rows.size());
    Pair means{};
    for (auto [x, y] : rows) { means[0] += x; means[1] += y; }
    means[0] /= n;
    means[1] /= n;
    Covariance matrix{};
    for (auto [x, y] : rows) {
        Pair d{x - means[0], y - means[1]};
        for (int i = 0; i < 2; ++i)
            for (int j = 0; j < 2; ++j)
                matrix[i][j] += d[i] * d[j];
    }
    for (auto& row : matrix)
        for (double& entry : row) entry /= n - 1;
    return matrix;
}

Grid cooccurrence(const Grid& levels, int dx, int dy) {
    Grid counts{};
    for (int y = 0; y < 4; ++y) {
        for (int x = 0; x < 4; ++x) {
            int nx = x + dx, ny = y + dy;
            if (nx >= 0 && nx < 4 && ny >= 0 && ny < 4) {
                int a = levels[y][x], b = levels[ny][nx];
                ++counts[a][b];
            }
        }
    }
    return counts;
}
def sample_covariance(rows):
    n = len(rows)
    if n < 2:
        raise ValueError("Sample covariance needs two or more observations")
    means = [sum(row[k] for row in rows) / n for k in range(2)]
    matrix = [[0.0, 0.0], [0.0, 0.0]]
    for x, y in rows:
        d = (x - means[0], y - means[1])
        for i in range(2):
            for j in range(2):
                matrix[i][j] += d[i] * d[j]
    return [[entry / (n - 1) for entry in row] for row in matrix]


def cooccurrence(levels, dx, dy):
    counts = [[0] * 4 for _ in range(4)]
    for y, row in enumerate(levels):
        for x, a in enumerate(row):
            nx, ny = x + dx, y + dy
            if 0 <= nx < len(row) and 0 <= ny < len(levels):
                b = levels[ny][nx]
                counts[a][b] += 1
    return counts
