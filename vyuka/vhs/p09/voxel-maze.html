Voxel Maze: nalaďte útoky

Původní voxelová grafika, klikací dílna útoků, export a import JSON. Samostatná výuková kopie verze v19 — nikoli pozdější Voxel Conquer s novou grafikou.

Stáhnout hru pro Windows 64-bit (ZIP)

Rozbalte celý archiv do zapisovatelné složky a spusťte WindowsDemo/VoxelMazeWorkshop.exe. Unity ani instalace nejsou potřeba.

Záměrně rozladěné zadání

Šestnáct hráčských útoků má náhodně nastavené poškození, časy, dosahy a některé účinky. Náhodný výchozí profil je pro všechny stejný a při restartu se nemění (seed 20261123). NPC, pasti, pohyb, grafika a zvuky zůstávají původní.

  1. Vyzkoušejte postavy. Najděte alespoň dvě konkrétní nerovnováhy.
  2. Otevřete ÚTOKY v editoru mapy nebo DÍLNU ÚTOKŮ v lobby. Vyberte postavu, slot LMB/RMB/Q/E a útok; upravte jeho parametry.
  3. Stiskněte AKTIVOVAT NÁVRH a změny otestujte na stejné mapě. Stejné DPS ještě neznamená stejně užitečné útoky.
  4. Přes EXPORT JSON uložte výsledek. Odevzdejte soubor a stručně popište: co se změnilo, proč a co ukázal test.

Export je ve složce WindowsDemo/Calibration/attacks-…json. Více postav může sdílet jedno ID útoku; pro nezávislé ladění vytvořte jeho vlastní kopii. Výchozí nastavení obnovuje rozladěné zadání, nikoli vzorové řešení. Návrh před ukončením hry exportujte.

Pro společné hraní použijte všichni tento balíček; host aktivuje návrh před kolem. Hra profil přenese ostatním. Během kola pravidla měnit nelze.

English: Windows workshop build with original voxel art and intentionally unbalanced, fixed randomized attack stats. Edit attacks, activate your draft, test it and export JSON. The in-game instructions are in Czech.
