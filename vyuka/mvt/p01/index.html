Vizualizace

  • Definice
  • Vizualizací se rozumí zobrazování skutečnosti, jejichž výsledky jsou znázorněny vnímané prostřednictvím zrakových receptorů. (wikipedie).
  • Definice
  • Způsob zobrazení dané informace pomocí některé z grafických reprezentací.
  • Definice
  • The use of computer-generated, interactive, visual representations of data to amplify cognition. (Card, Mackinlay, Shneiderman, 1999).
  • Definice
  • Tool to enable a User insight into Data

Interaktivní ukázka GRAFIT


Porovnejte rozlišení, zorný úhel a snímkovou frekvenci. Změny ukazují nároky na obraz a čas dostupný pro jeden snímek.




GRAFIT · ilustrační model. Průměrná hustota px/° = šířka / zorný úhel; čas snímku = 1000 / Hz. Nezahrnuje optiku, zkreslení, binokulární zobrazení, režii ani skutečný výkon zařízení. Poměr stran je schematický.
