# Lecture word wrapping

Keep complete words in presentation text. Prefer several short lines to an arbitrary break inside a word. Use normal word boundaries, no automatic hyphenation or `overflow-wrap:anywhere` / `word-break:break-all` in prose. Headings and text blocks shrink only if one complete word exceeds their available line width, never merely because the paragraph has many lines. URLs and slash-separated lists may wrap at their separators. Integrity hashes and code remain technical content in bounded panels.

`apply-teaching-typography.cjs` runs at the end of `build-teaching-pages.cjs`. Its canonical CSS/JS inputs live beside it. Imported author styles and source hashes stay intact; this is a GRAFIT presentation adaptation. The helper validates imported HTML and archive hashes, excludes historical backup HTML, versions shared assets, refreshes the copy manifest, and updates existing offline downloads without changing source PDFs or illustrations. The source manifest records the initial pre-typography copy hash.
