Sources and review

Knowing where each result comes from and what was added.

A visual notebook of the MOST project · September 2026

Three layers of certainty

The original photograph records visible conditions. A derived reference prepares them for modelling but can introduce errors. Generative completion offers a possible solution for missing surfaces. These layers are retained separately so decisions can be reassessed.

Technical checks and historical accuracy

UV, file and geometry checks expose technical faults. Historical accuracy still needs human assessment against sources. A result may pass technically while retaining uncertain colours, ornament discrepancies or an inferred rear facade.

Preserving the version history

Examples were selected from local project outputs and manifests as of 8 September 2026. Originals remain preserved. Web previews are reduced copies; the source and checksum list allows their inputs to be traced.
