Blender and a compute server

Ondra Sakala’s StableGen connects Blender to ComfyUI on the same computer or a separate server. It prepares views and automatically projects and blends resulting images onto the model. It also supports references and UV completion.

FRONTs in an automated workflow

In the project use described here, Ondra follows FRONT preparation with automated mapping. For Kulová v5, we instead controlled registration by storeys and opening edges, protected photographic strips and used custom Blender mapping with the built-in image model. Neither StableGen nor ComfyUI ran for that version.
